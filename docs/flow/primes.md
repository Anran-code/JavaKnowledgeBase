# 素数输出复盘

试除到平方根与方法前提。

## 为什么只试到平方根？

若 n 是合数，可以写成 a×b。如果 a、b 都大于 √n，乘积就会大于 n，因此必有一个因子不大于 √n。找不到这个范围里的因子，就不需要继续尝试。

## 你的两层逻辑

`pnPrint()` 遍历 101～200，偶数直接 continue；剩下的都是大于 2 的奇数。`checkPrime()` 从 3 开始，每次加 2，只检查奇数因子。

在这个调用前提下，题目的输出是正确的，共 21 个素数：

```text
101 103 107 109 113 127 131
137 139 149 151 157 163 167
173 179 181 191 193 197 199
```

## 输出正确，不代表辅助方法适用于所有输入

当前 `checkPrime(4)` 会直接返回 true，因为没有检查因子 2；`checkPrime(1)` 也会返回 true。它依赖调用者先筛选输入。

若要把它写成通用方法，判断顺序应为：

1. 小于 2：不是素数。
2. 等于 2：是素数。
3. 大于 2 的偶数：不是素数。
4. 其余奇数：从 3 开始，只尝试不超过平方根的奇数因子。

循环边界必须包含平方根，否则 121 可能漏掉因子 11。扩展到较大整数时，`i <= num / i` 可以避免 `i*i` 的整数溢出。

## 何时需要更快的方法？

101～200 这种小范围使用试除法足够直观。若要一次求出很大范围内的所有素数，可以学习筛法：发现素数后批量标记它的倍数。当前先理解“缩小候选数字”和“缩小试除范围”这两步优化。

# 这本手册怎样整理

[返回总目录](/)

这是你的个人 Java 知识库。总目录已按现有笔记和源码分成 8 个部分，Java 基础提供完整样章，其余章节先建立目录。目标是像翻书一样阅读，也能通过关键词快速找回学过的内容。

## 三种材料，各司其职

| 材料 | 在这里怎样使用 |
| --- | --- |
| 原笔记 `notes/01基础.md` | 提供知识点范围和你曾经关注的问题 |
| 你的 Java 练习 | 展示真实代码，保留原始写法 |
| 整理后的讲解 | 校正遗漏，重排阅读顺序，解释代码和易错点 |

[下载原始基础笔记快照](/source-notes.md){download}

## 第一版已经整理什么？

本章包含 10 个知识小节，覆盖程序入口、基本类型、类型转换、方法、重载、Scanner、随机数、数组、异或和格式化输出，以及综合练习。源代码来自 `01-HelloWorld`、`02-basic` 与 `04-array`。

原笔记里引用类型转换、instanceof 等涉及继承的内容，只做了定位说明，留待面向对象章节展开。

## 原始代码会被修改吗？

不会。知识库在独立目录 `D:\JavaKnowledgeBase` 内，只读取 `D:\JavaCode` 的指定文件。展示的是同步时的快照，原笔记、源文件和 IDEA 项目配置不会被改写。

发现问题时，在讲解中标出。例如数组练习中“随机坐标写死为 5”的问题，原代码仍原样展示，修订建议在正文里说明。

## 怎样更新源码？

关闭本地服务后重新启动，会自动重新同步。也可以在知识库目录执行：

```sh
npm run sync
npm run build
```

修改正文时，编辑 `docs/basics/` 下的 Markdown。后续可以按相同格式继续增加章节。

## 本地使用与已读标记

站点只监听本机地址，不需要账号，也没有上传、统计或在线 AI 服务。首次安装依赖需要联网，安装完成后阅读、搜索和构建均使用本地资源。

“已读”状态保存在当前浏览器的 localStorage 中，只是个人阅读标记；清除浏览器数据会重置，不影响笔记和源码。

## 搜索怎么用？

点击顶部搜索，或按 Ctrl / Cmd + K。可以搜索中文概念、API 或类名，例如“强制转换”“Scanner”“nextLine”“MethodOverload”。知识点正文中已补充相关词，源码索引用于进一步查看完整文件。
